Function is Value

▸ Function adalah value, maka function bisa ditambahkan ke property value, seperti berikut :

                const person = {
                    name: 'Edward',
                    age: 25,
                };

                function sayHello() {
                    console.log('Hello!');
                };

                person.sayHello = sayHello;

                person.sayHello();                     Terminal result : Hello!

▸ Bisa juga menggunakan function expression , bisa juga function declaration

                const person = {
                    name: 'Edward',
                    age: 25,
                };

                person.sayHello = function() {         function sayHello adalah bagian dari object.
                    console.log('Hello!');             Maka kita memanggilnya dengan METHOD sayHello.
                };

                person.sayHello();

▸ *note, kalo function dimiliki / menjadi object property, makan bukan lagi menjadi function, melainkan METHOD
