Function is Value

▸ Function adalah value, maka function bisa ditambahkan ke property value, seperti berikut :

                const person = {
                    name: 'Edward',
                    age: 25,
                };

                function sayHello() {
                    console.log('Hello!');
                };

                person.sayHello = sayHello;

                person.sayHello();                     Terminal result : Hello!

▸ Bisa juga menggunakan function expression , bisa juga function declaration

                const person = {
                    name: 'Edward',
                    age: 25,
                };

                person.sayHello = function() {         function sayHello adalah bagian dari object.
                    console.log('Hello!');             Maka kita memanggilnya dengan METHOD sayHello.
                };

                person.sayHello();

▸ *note, kalo function dimiliki / menjadi object property, makan bukan lagi menjadi function, melainkan METHOD

'THIS' for Methods 
                const rectangle = {
                    width: 5,
                    height: 3,
                };

                function getRectangleArea(r) {
                    return r.width * r.height;
                }

                console.log(getRectangleArea(rectangle));              Terminal result : 15

▸ Function getRectangleArea(r) : (r) parameter untuk object apapun yg memiliki property width & height

▸ Console.log(getRectangleArea(rectangle)) ; : (rectangle) argumen dari function getRectangleArea ini adalah object 'rectangle' jadi masuk ke parameter (r)

*Note : ada kejanggalan daripada contoh ini, karena seharusnya function getRectangleArea(r) ini satu kesatuan dengan object rectangle

Maka dirubah menjadi seperti berikut :

                const rectangle = {
                    width: 5,
                    height: 3,
                };

                rectangle.getArea = function() {
                    return this.width * this.height;
                }

                console.log(rectangle.getArea());

▸ Function nya ditambahkan ke object property & tidak ada parameter, melainkan ditambah this.width * this.height

▸ Lalu 'This' apa ?

▸ This ini isinya tidak diketahui / tidak bisa ditentukan, kecuali method .getArea dipanggil

▸ Jadi this dari case diatas, isinya adalah object property rectangle

*Note : karena menurut spesifikasi JavaScript variable 'this' adalah value sebelum tanda titik console.log(this.widht); = (rectangle.widht);

Apa fungsi 'this'?

▸ Ketika ada 2 operator, yg akan di calculate menggunakan 1 function (method)

▸ Maka peran this.width * this.height ini menjadi dinamis, karena 'this' nya tergantu apa yg di call method nya di console.log

*note : tidak bisa menggunakan Arrow function ('=>'), karena Arrow function tidak memiliki 'this' jadi dikhususkan untuk function expression & function declaration
(Kalo dipanggil dalam terminal node.js maka terminal value nya adalah Empty Object)


▸ 3rd Case : Another example

                const circle = {
                    radius: 5,
                    calculateArea: function() {
                        return Math.PI * this.radius ** 2;
                    },
                    calculatePerimeter: function() {
                        return 2 * Math.PI * this.radius;
                    },
                };

                const area = circle.calculateArea();
                const perimeter = circle.calculatePerimeter();

                console.log(`area: ${area}`);                      Terminal result: area: 78.53------
                console.log(`perimeter: ${perimeter}`);                             perimeter: 31.415------
