Object to Primitive type

▸ Object type dibentuk menggunakan Primitive type

▸ JavaScript hs 8 data types, and 2 different types, it contains :

number Primitive Types
string
boolean
undefined
null
symbol
object Obect Types

Jika ada kasus seperti ini : 

           const result = obj1 - obj2;

Bagimana cara supaya object bisa dijumlahkan dengan object lain?

Yaitu mengubah object dari asalny Object Type -> Primitive Type


▸ Ada sesuatu yang dipakai JavaScript untuk mengubah Object menjdi primitive type :
    yaitu menggunakan TYPE COERCION

Java script melakukan type Coercion menggunakan Hint

ada 3 type coercion yg digunakan HINT

                Hint
                'number'
                'string'
                'default'

▸ Contoh kasus berikut yg menghasilkan type Hint nya adalah 'number' :

                const result = obj1 - obj2;
                                    |
                                    ▾
                                Hintnya adalah 'number'
                

                const result = obj1 > obj2;
                                    |
                                    ▾
                                Hintnya adalah 'number'

                
                const result = +obj1
                               |
                               ▾
                        Hintnya adalah 'number'

▸ Khusus operator + binary type hint nya akan selalu 'default' karena ada 2 kemungkinan yg bisa terjadi, antara menjumlahkan 'number' / menambahkan 'string', dalam Java script hal tersebut tidak akan dijalankan secara langsung, jadi dia akan kembali ke 'default'

                const result = obj1 + 'Hello'
                                    |
                                    ▾
                                Hintnya adalah 'default'


                const result = obj1 + obj2
                                    |
                                    ▾
                                Hintnya adalah 'default'

▸ Jadi kasus di atas, object type + object type, akan selalu menghasilkan type hint 'default'


▸ Berikut contoh kasus supaya object type nya berubah menjadi type hint 'number', maka diberi tambahan unary operator +date'

                const date = new Date(2011, 1, 1);     construction function

                console.log(+date);    unary operator


Proses JavaScript mengubah object menjadi Primitive type menggunakan Symbol

▸ Contoh kasus berikut menggunakan System Simbol (Symbol dari java script): Symbol.toPrimitive :

                const person = {
                    name: 'Edward',
                    salary: 5000,
                };

                person[Symbol.toPrimitive] = function(hint) {      parameternya hint
                    if (hint === 'number') {
                        return this.salary;
                    }
                    
                    return this.name
                }


DEMO Symbol.toPrimitive 
                function Person(name, salary) {
                    this.nme = name;
                    this.salry = salary;
                    this[Symbol.toPrimitive] = function(hint) {
                        return hint === 'number' ? this.salary : this.name;       menggunakan if else ternary operator
                    }
                }

                const person1 = new Person('Edward', 8000);        construction function
                const person2 = new Person('John', 5000);          construction function

                console.log(person1 - person2);                    Terminal result : 3000

▸ Di contoh kasus tersebut, person1 - person2, type hint nya sudah otomatis 'number', jadi masing² object 1 & 2 memanggil this. Salary, lalu dijumlahkan

DEMO 2 Symbol obj.toString( ) or obj.valueOf 
                const person = {
                    name: 'Edward',
                    salary: 5000,
                    toString: function() {
                        return this.name
                    },
                    valueOf: function() {
                        return this.salary;
                    },
                };

                console.log(+person);                  Terminal result : 5000
                console.log('Hello' + person);         Terminal result : Hello 5000

▸ +person menampilkan 5000, karena type hintnya number, jadi yg terpanggil pertama yaitu person.valueOf()
