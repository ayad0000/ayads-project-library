How Objects are Copied & Ternary Operator<
Example 1 Copied VARIABLE 
            let price = 100;
            let copiedPrice = price;               menduplikat variable price

            copiedPrice = 50;

            console.log(copiedPrice);              Terminal result : 50
            console.log(price);                                      100

▸ Proses dibalik layar :

            let price = 100;
            let copiedPrice = price;               

            copiedPrice = 50;                         price                        copiedPrice
                                                        ⇑ bind                          ⇑ bind
            console.log(copiedPrice);           0 1 1 0 0 1 0 0     Clone ⟹     0 0 1 1 0 0 1 0              convert to binary               
            console.log(price);                                                  Value in memory is set to 50

▸ let price = 100; Pertama ini disimpan dalam bentuk tegangan listrik, yaitu binary 01100100
▸ Lalu dikondisikan / bind (diikat) dengan variable price
▸ Lalu copiedPrice akan dicopy / clone ke penyimpaann memory lain
▸ Lalu di bind lagi ke vaariable copiedPrice, binary code nya berubah menjadi number 50



Example 2 copied OBJECT 
            let rectangle = { width: 5, height: 3 };
            let copiedRectangle = rectangle

            copiedRectangle.width = 10;

            console.log(copiedRectangle.widht);    Terminal result : 10
            console.log(rectangle.widht);                            10 otomatis terubah dari obj copiedRectangle

▸ Proses dibalik layar :

            let rectangle = { width: 5, height: 3 };
            let copiedRectangle = rectangle                 rectangle           copiedRectangle
                                                                ⇑ bind                 ⇑ bind
            copiedRectangle.width = 10;                     reference              reference
                                                                |                      |
            console.log(copiedRectangle.widht);                 |                      |
            console.log(rectangle.widht);                       |                      |
                                                            {                          |
                                Width is update to 10         width: 10, ______________|
                                                              height: 3,                                                               
                                                            }

▸ reference (acuan) mengarah ke memory yg menyimpan object property
▸ Lalu yg di bind bukanlah value, melainkan reference
▸ Lalu copiedRectangle nya itu yg dicopy, bukan value nya, melainkan reference
▸ Jadi 2 reference tersebut sama-sama mengarah ke 1 lokasi value object

*Note : Maka kalo diganti property value nya, akan otomatis merubah value property nya, bukan merubah reference nya

Ternary Operator

 
                boolean value ? return if true : return if false

▸ Disebut Ternary Operator karena operannya ada 3, serta simbolnya yaitu '?, :'

*Note : Kategori operatornya hanya 1, jadi nama kategori juga 'ternary operator'


                boolean value ? return if true : return if false
                       |               |                 |
                    operan          operan            operan

▸ Kalo boolean value 'true', maka return setelah tanda '?', kalo false setelah tanda ':'

*Note : Syntax lain untuk IF ELSE

Example 
                    temperature >= 37 ? 'sick' : 'normal'
                                            |
                                Will be returned if true

▸ Kalo hasilnya true (diatas 37) returnnya 'sick, kalo false (dibawah 37 'normal'



DEMO 
                    const temperature1 = 38;
                    const temperature2 = 36.5;

                    const result1 = temperature1 >= 37 ? 'sick' : 'healthy';
                    const result2 = temperature2 >= 37 ? 'sick' : 'healthy';

                    console.log(result1);          Terminal result : sick
                    console.log(result2);                            healthy

▸ kalo ada 3 kemungkinan, Syntax nya seperti ini :

                    const temperature = 36.5;

                    const result = temperature >= 37 ? 'sick' : (temperature <= 35 ? 'hypothermia' : 'healthy');

                    console.log(result);           Terminal result : normal

▸ kalo ada lebih dari 3 kemungkinan, Syntax nya seperti ini :

                    const score = 80;
                    const grade = score < 60 ? 'F' :
                        score < 70 ? 'D' :
                        score < 80 ? 'C' :
                        score < 90 ? 'B' : 'A';

                    console.log(grade);            Terminal result : B

*Note : grade nya dari bawah ke atas


▸ Opsi ke-2 supaya penulisannya lebih Estetik :

                    const score = 80;
                    const grade = score < 60 ? 'F' 
                        : score < 70 ? 'D' 
                        : score < 80 ? 'C' 
                        : score < 90 ? 'B' : 'A';

                    console.log(grade);            Terminal result : B
