Cara retrieve property nya dari symbol 
                const readline = require('readline-sync');
                const questionSymbol = Symbol();
                readline[questionSymbol] = 'How are you?';
                console.log(readline[questionSymbol]);

Terminal result : How are you?

▸ Local symbol

                const person = {
                    firstName: 'Edward',
                    age: 20,
                };

                const idSymbol = Symbol('id');     (hanya deskription, bukan property key nya)
                const citySymbol = Symbol('city'); (hanya deskription, bukan property key nya)

                console.log(idSymbol === citySymbol);

Terminal result : false
Symbol pasti unik dikarenakan semua property key dalam Symbol akan disimpan ke Symbol Registry secara otomatis 

                person[idSymbol] = 'KU0001';
                person[citySymbol] = 'Jakarta';

                console.log(person);

Terminal result : { id : KU0001, city ; Jakarta }
dalam Terminal result, property key nya hanya akan menampilkan Symbol description, itu disebabkan karena symbol berfungsi untuk melindungi / menyembunyikan property key yg seharusnya tidak ditampilkan oleh programer lain pada saat buka project / library kita
